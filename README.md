# Concave Insights Custom Survey System

A custom survey platform designed for market research studies running on strict 15-day project cycles. The system validates and parses plain-text questionnaire definitions into structured data, enforces multi-branching logic, screening rules, and quotas, and collects respondent feedback through a generic, mobile-first interface.

- **Stack**: FastAPI, MySQL 8, Angular
- **Design Specifications**: Technical architecture, entity relationships, user flows, and design decisions are documented in the [`/design`](design/) directory.

*Status: Architecture and design specifications complete; implementation in progress.*
